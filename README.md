# STM32F4 智能搬运小车

本工程面向 **2026 年四川省大学生工程实践与创新能力大赛搬运赛项**，使用 STM32F407 作为主控，配合 K230 视觉模块、HWT101 陀螺仪、机械臂、舵机和串口屏，完成智能搬运任务。

目前已完成全流程实车联调，所有功能已跑通。设备初始化完成后，按下一键启动即可自动执行任务，当前单次完整流程运行时间约 **3 分钟**。

## 主要功能

- **视觉识别**：通过 K230 识别二维码任务信息、料盘物料及圆环位置。
- **底盘控制**：支持前后、左右、斜向移动和转向，结合 HWT101 进行航向校准。
- **视觉定位**：根据视觉偏差调整小车位置，对准取料及放料区域。
- **自动抓放**：机械臂配合舵机完成取料、车载料盘存放、粗加工区放取和暂存区同色叠放。
- **任务执行**：支持两条路线，完成两轮搬运任务并返回。
- **交互与补光**：通过串口屏启动任务，按视觉模式联动 PWM 补光，并保留串口调试接口。

## 硬件组成

| 模块 | 用途 |
| --- | --- |
| STM32F407 主控 | 运行控制程序，协调底盘、机械臂与外设 |
| K230 视觉模块 | 二维码、物料及圆环识别 |
| HWT101 陀螺仪 | 航向采集与角度校准 |
| 四轮底盘及电机驱动 | 平移、斜向移动和转向 |
| 三轴机械臂及电机驱动 | 旋转、升降与伸缩 |
| 舵机夹爪 | 抓取与释放物料 |
| 串口屏 | 一键启动、任务信息及页面交互 |
| 补光灯 | 为视觉识别提供照明，支持亮度调节 |

## 运行流程

1. 上电并等待设备初始化、陀螺仪航向初始化完成。
2. 在串口屏选择对应路线，按下一键启动。
3. 小车自动前往原料区，识别二维码并完成第一批取料。
4. 在粗加工区放料、取回，再前往暂存区放料。
5. 返回原料区完成第二批取料，再次经过粗加工区。
6. 在暂存区按颜色叠放第二批物料，完成任务并返回。

当前实车完整流程约 3 分钟，实际用时会随任务、场地和识别情况变化。

## 开发与编译

- 开发环境：Keil MDK，当前工程配置使用 ARM Compiler 5.06。
- 芯片支持包：当前工程配置为 `Keil.STM32F4xx_DFP.3.1.1`。
- 打开工程：`Project.uvprojx`。

安装相应编译器及芯片支持包后，在 Keil 中打开工程，执行 **Rebuild**，再通过调试器下载到主控。

本仓库保存 STM32 端控制工程，运行时需配套 K230 视觉程序和串口屏界面。运动距离、机械臂坐标、视觉换算系数和动作等待时间按当前实车标定，更换机械结构或场地后需要重新确认。

## 工程结构

- `Hardware/`：硬件驱动代码
- `System/`：系统功能代码
- `User/`：应用程序代码
- `Libraries/`：STM32 相关库文件
- `Start/`：启动文件与芯片基础定义
- `RTE/`、`DebugConfig/`：设备运行环境与调试配置
- `Project.uvprojx`：Keil 工程文件

`Hardware/` 中的主要模块：

| 文件 | 功能 |
| --- | --- |
| `Motor.c/.h` | 底盘运动控制与运行时间估算 |
| `Arm.c/.h`、`Servo.c/.h` | 机械臂与夹爪控制 |
| `HWT101.c/.h` | 陀螺仪通信与航向校准 |
| `VisionSerial.c/.h`、`Vision_work.c/.h` | K230 通信、视觉数据解析和定位 |
| `Work.c/.h` | 路线、取料、放料和叠放流程 |
| `tjc.c/.h` | 串口屏交互 |
| `Light.c/.h` | 补光灯 PWM 控制 |

`Objects/`、`Listings/` 等编译输出和本机 uVision 配置由 `.gitignore` 排除。
