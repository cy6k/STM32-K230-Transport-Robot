# STM32F4 智能搬运小车

本工程面向 **2026 年四川省大学生工程实践与创新能力大赛搬运赛项**，使用 STM32F407 作为主控，配合 K230 视觉模块、HWT101 陀螺仪、机械臂、舵机和串口屏，完成智能搬运任务。

目前已完成全流程实车联调，所有功能已跑通。设备初始化完成后，按下一键启动即可自动执行任务，当前单次完整流程运行时间约 **3 分钟**。

## 主要功能

- **视觉识别**：通过 K230 识别二维码任务信息、料盘物料及圆环位置。
- **底盘控制**：支持前后、左右、斜向移动、任意角度平移和转向，可设置平移速度与加速档位，并结合 HWT101 进行航向校准。
- **视觉定位**：料盘使用首个有效帧进行单次位置修正；圆环定位联合视觉和陀螺仪，交替复核位置与朝向。
- **自动抓放**：完成两批连续取料、车载料盘存放、粗加工区放取和暂存区同色叠放，抓放坐标和夹爪角度集中配置。
- **任务执行**：支持两条路线，完成两轮搬运任务并返回。
- **交互与补光**：支持串口屏或两个实体按键启动对应路线，按视觉模式联动 20kHz 硬件 PWM 补光，并保留串口调试接口。

## 硬件组成

| 模块 | 用途 |

| K230 视觉模块 | 二维码、物料及圆环识别 |
| HWT101 陀螺仪 | 航向采集与角度校准 |

| 补光灯 | PB0／TIM3_CH3 输出 20kHz 硬件 PWM，支持 0～100% 亮度调节 |

## 运行流程

1. 上电后等待设备初始化、陀螺仪航向初始化和机械臂准备动作完成。
2. 在串口屏选择对应路线并启动，或按实体按键 1／2 启动对应路线。
3. 小车自动前往原料区，识别二维码并完成第一批取料。
4. 在粗加工区放料、取回，再前往暂存区放料。
5. 返回原料区完成第二批取料，再次经过粗加工区。
6. 在暂存区按颜色叠放第二批物料，完成任务并返回。

当前实车完整流程约 3 分钟，实际用时会随任务、场地和识别情况变化。

实体按键使用下拉输入，按下时连接 3.3V，包含按下与释放消抖。扫码阶段会持续等待有效识别结果，成功后直接切换到料盘模式；路线中也会提前切换后续视觉模式。

## 定位与抓放控制

### 料盘取料

进入料盘模式后，使用首个有效视觉帧，按当前标定系数先左右、再前后修正一次。修正完成后不再复检 x、y，保留期间接收的数据，等待颜色编号 z 变化以确定转盘物料位置，再执行连续三次抓取。程序通过 `Locate_ZY` 记录本轮左右修正脉冲，两条路线均在每批取料后反向补回这段横向位移。

两条路线还通过 `Catch_Data` 适应任务中转盘位置的变化：每批取料前横移指定脉冲并校准航向，取料完成后反向横移返回原路线。当前 `Catch_Data` 为 1000 脉冲。

第三次抓取前等待时间由 `Work.c` 中的 `Grap_Delay` 设置，当前为 500ms。第三抓使用转盘再次换位后的预测位置，转盘转速或停留时间变化后需重新确认。

### 圆环定位与航向复核

模式 3 使用 `orient1()`，用于两批物料的普通圆环放料；模式 5 使用 `orient2()`，用于第二批同色叠放。两者分别配置位置与航向判据：

| 用途 | x、y 允许偏差 | 航向允许误差 | 位置确认 |
| --- | --- | --- | --- |
| 模式 3／普通放料 | ±1 像素 | ±0.10° | 连续三帧合格 |
| 模式 5／同色叠放 | ±3 像素 | ±0.10° | 连续三帧合格 |

定位过程：

1. 根据一帧视觉数据，将左右、前后偏差换算为一次合成平移。普通放料时，各轴在容差内不动，超差但不超过 3 像素按 50% 修正，更大偏差按 100% 修正；叠放时超差轴按 100% 修正。
2. 等待本次合成运动的理论用时加 20ms，期间继续接收数据，不用新帧改写当前运动指令；结束后丢弃运动期间的旧视觉帧，使用新陀螺仪数据将朝向校准到最近的 90° 整数倍。
3. 清除旧视觉帧，重新复核位置；若仍超差，则重复位置与朝向修正。
4. 朝向满足当前模式的允许误差，且此后连续三帧 x、y 偏差均在对应范围内，才结束定位。

以上数值是当前程序的完成判据，不等同于实车绝对定位精度。运动等待采用位置指令的理论用时或固定延时，未使用电机到位反馈。

`Move()` 按位移比分配轮速，四轮使用调用方指定的同一加速档位并同步启动；各轮到位时间可不同，合成平移轨迹不保证严格直线。定位运动尚未结束时切换视觉模式，会先停止底盘四轮。

### 视觉模式与补光

| 模式 | 功能 | 补光灯 |
| --- | --- | --- |
| 1 | 二维码识别 | 保留当前亮度 |
| 2 | 料盘识别与单次修正 | 50% 亮度 |
| 3 | 粗加工区圆环定位 | 50% 亮度 |
| 4 | 休息 | 关闭 |
| 5 | 备用圆环定位，供暂存区叠放使用 | 50% 亮度 |

### 标定参数

`Hardware/Work.c` 顶部集中定义夹爪开合角度、抬升高度及各取放位置：`Claw_*` 为夹爪参数，`SX_Lift_*` 为抬升位置，`V*`、`C*`、`R*` 分别对应车载料盘、转盘和圆环，`Catch_Data` 为转盘位置变化的横移补偿量。路线距离、视觉换算系数及等待时间按当前实车标定。

## 开发与编译

- 开发环境：Keil MDK，当前工程配置使用 ARM Compiler 5.06。
- 芯片支持包：当前工程配置为 `Keil.STM32F4xx_DFP.3.1.1`。
- 打开工程：`Project.uvprojx`。

安装相应编译器及芯片支持包后，在 Keil 中打开工程，执行 **Rebuild**，再通过调试器下载到主控。

本仓库保存 STM32 端控制工程，运行时需配套 K230 视觉程序和串口屏界面。运动距离、机械臂坐标、视觉换算系数和动作等待时间按当前实车标定，更换机械结构或场地后需要重新确认。

## 工程结构

- `Hardware/`：硬件驱动代码
- `System/`：系统功能代码
- `User/`：应用程序代码
- `Libraries/`：STM32 相关库文件
- `Start/`：启动文件与芯片基础定义
- `RTE/`、`DebugConfig/`：设备运行环境与调试配置
- `Project.uvprojx`：Keil 工程文件

`Hardware/` 中的主要模块：

| 文件 | 功能 |
| --- | --- |
| `Motor.c/.h` | 底盘运动、可配置平移参数与理论运行时间估算 |
| `Arm.c/.h`、`Servo.c/.h` | 三轴机械臂与夹爪控制 |
| `HWT101.c/.h` | 陀螺仪通信与航向校准 |
| `VisionSerial.c/.h`、`Vision_work.c/.h` | K230 通信、数据解析、单次料盘修正及圆环位置与航向复核 |
| `Work.c/.h` | 两条路线、连续取料、放料、同色叠放及集中标定参数 |
| `tjc.c/.h` | 串口屏交互 |
| `Key.c/.h` | 两个实体启动按键的读取与消抖 |
| `Light.c/.h` | PB0／TIM3_CH3 硬件 PWM 补光控制 |

`Objects/`、`Listings/` 等编译输出和本机 uVision 配置由 `.gitignore` 排除。
